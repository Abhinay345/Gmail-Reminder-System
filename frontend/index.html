Google Cloud Client setup instructions

Steps to generate Credentials in Google Console:

  1. Go to Google Cloud Console and create a new project.
  2. Navigate to the APIs & Services Dashboard, click "Enable APIs and Services", search for Gmail API, and click Enable.
  3. Set up the OAuth Consent Screen: Choose External user type, fill basic email info, and add scope: https://www.googleapis.com/auth/gmail.readonly and https://www.googleapis.com/auth/gmail.send. Add your email as a Test User.
  4. Go to Credentials -> click "Create Credentials" -> select OAuth Client ID.
  5. Choose application type Web Application.
  6. Under Authorized Redirect URIs, add: http://localhost:8000/api/auth/callback.
  7. Click Create, copy the resulting Client ID and Client Secret, paste them here and save!
